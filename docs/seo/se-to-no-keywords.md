## 🔑 Похожие ключи, которых НЕ было в SE-списке (Google подсказал) — новые ядра
Это самое ценное «схожее» — то, чего в шведском списке не было, а в Норвегии есть спрос:
- **hms kort — 1K-10K** (+ hms kort pris/bygg, bestille/mistet/sjekke/midlertidig hms kort, byggekort, arbeidstilsynet) — САМОЕ БОЛЬШОЕ
- **sha plan / sha plan eksempel — 100-1K**
- **timepris snekker / tømrer — 100-1K**
- **faktura mal / fakturamal — 100-1K** (тренд +900%)
- **ns 8405 / norsk standard — 100-1K** (byggekontrakt)

## Вывод по объёмам
- Топ NO из перевода SE-списка: **timeregistrering/app 500**, **timeliste/app 100-1K**.
- SE-гиганты 5400/2400 в NO схлопываются в 500/10-100 (норв. рынок меньше).
- **stämpelklocka → stemplingsur почти мёртвый (0-10)** в NO.

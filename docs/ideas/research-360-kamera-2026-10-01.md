# 360°-камера для проверки стройки по договору — исследование (2026-10-01)

Пройти объект с 360°-камерой и снять его с привязкой к плану сегодня умеют готовые продукты. OpenSpace делает это за индивидуальную цену, которая зависит от годового объёма строительства. Скандинавский Dalux Field умеет то же через функцию SiteWalk: камера крепится на каску, снимки привязываются к плану и получают дату, их можно сравнить с BIM. Сверку с контрактом, сметой или платёжным графиком в проверенных источниках не обещает ни один из этих продуктов. Dalux явно ограничивается ручным сравнением с BIM. Технически свой MVP собрать можно: у Insta360 и Ricoh THETA есть SDK и API для управления съёмкой, а исследователи считают потребительские 360-камеры дешёвой заменой LiDAR. Трудная часть — сопоставление снимков со сметой. Её проверенные источники не покрывают, это остаётся НИОКР. Сегмент частных клиентов (Byggtorg) существует, но он офлайновый: Anticimex и Badrumshjälpen продают выездные проверки по фиксированной цене от 2 900 до 9 995 kr. Споры тоже есть: в ARN около 3 000 жалоб в год в категории Bostad. Рекомендация: в ByggExp делать лёгкую функцию «360-dokumentation / egenkontroll» (снимки на плане, отметки, размытие людей, отчёт) без обещаний ИИ-сверки со сметой. Для Byggtorg продавать сервис «oberoende kontroll» как человеческую услугу партнёров с фото-/360-протоколом, а не как автоматическую систему.

## Findings

- [high] OpenSpace продаёт только по индивидуальному запросу и ориентирован на крупных подрядчиков. Публичных цен нет. Цена зависит от годового объёма строительства (ACV) и тарифа (Core или Enterprise), а не от числа пользователей или проектов. В Core входит безлимитная съёмка со смартфона, 360-камеры и дрона, визуальное сравнение с BIM и инструменты для замечаний и RFI. ИИ-трекинг прогресса продаётся отдельно как дополнение OpenSpace Track.
  Источники: https://www.openspace.ai/pricing/
- [high] Dalux Field (Дания), самый близкий скандинавский аналог, имеет функцию Reality Capture/SiteWalk. Прогулку запускают на чертеже, 360-камера закреплена на каске. Снимки автоматически получают дату и привязку к месту в проекте, их можно сравнить с BIM и облаками точек. ИИ-распознавание прогресса и сверка с затратами или контрактом не заявлены.
  Источники: https://www.dalux.com/solutions/reality-capture/, https://www.dalux.com/solutions/sitewalk/
- [medium] Базовая 360-документация (прогулка с привязкой к плану) стала массовой функцией. Ценность и отличие от конкурентов — в автоматической сверке с графиком, сметой или контрактом. Ни у одного проверенного продукта такая сверка не подтверждена.
  Источники: https://www.openspace.ai/pricing/, https://www.dalux.com/solutions/reality-capture/
- [high] Железо и SDK для своего MVP есть. Android SDK Insta360 (X3/X4/X5, ONE RS и др.) даёт подключение, съёмку, загрузку файлов и экспорт. Доступ выдают по заявке, для передачи данных нужен Wi‑Fi, превью идёт через отдельный Media SDK, а репозиторий на GitHub больше не обновляется. У Ricoh THETA есть открытый Web API (OSC), Bluetooth API и USB API. RICOH360 Cloud API тоже выдают только по заявке.
  Источники: https://github.com/Insta360Develop/Android-SDK, https://docs.ricoh360.com/
- [medium] Потребительские 360-камеры со встроенным IMU в исследованиях считаются дешёвой альтернативой LiDAR для мониторинга прогресса, но по точности они ему уступают. Локализация через визуально-инерциальный SLAM всё ещё страдает дрейфом, поэтому бенчмарк Hilti/Trimble/Oxford 2026 года использует априорные данные с плана этажа.
  Источники: https://arxiv.org/abs/2607.06464
- [high] Снимки, на которых можно узнать людей, — это персональные данные по GDPR. Работодателю не стоит опираться на согласие сотрудников. Типичное основание — законный интерес (ст. 6(1)(f)) с тестом баланса и уведомлением на объекте. Kamerabevakningslagen касается стационарных камер. 360-камеру, которую несёт человек, этот закон, скорее всего, не охватывает, но GDPR действует.
  Источники: https://www.edpb.europa.eu/sites/default/files/files/file1/edpb_guidelines_201903_video_devices_en_0.pdf, https://www.imy.se/vanliga-fragor-och-svar/vilka-regler-finns-det-for-att-satta-upp-en-bevakningskamera-pa-en-byggarbetsplats/
- [high] Конфиденциальность нужно закладывать в дизайн. По EDPB необратимое размытие считается удалением данных. Но размытия одних лиц может не хватить: людей узнают по одежде, бейджам или персональному журналу объекта (personalliggare). В OpenSpace размытие включается только по запросу в поддержку, действует лишь на будущие съёмки и пропускает часть лиц. Заказчик — контролёр данных, вендор — обработчик. Заказчик должен уведомить людей на объекте, а снимать можно в нерабочее время.
  Источники: https://www.edpb.europa.eu/sites/default/files/files/file1/edpb_guidelines_201903_video_devices_en_0.pdf, https://support.openspace.ai/hc/en-us/articles/41950625566611-Face-Blurring-in-OpenSpace
- [high] Частные клиенты в Швеции уже платят за независимый контроль ремонта по фиксированной цене. Anticimex Byggsäkring: ванная 9 995 kr, кухня 5 295 kr, крыша 9 995 kr, фасад 9 995 kr, дренаж 5 295 kr. В пакет входят консультация до начала работ, проверки по ходу работ на соответствие договору и отраслевым нормам и итоговый протокол. Badrumshjälpen: проверка ванной 3 900 kr, точечная проверка 2 900 kr (с НДС, плюс выезд), протокол с фото в течение 48 часов. Это выездные проверки специалистом, а не автоматическая сверка по съёмке.
  Источники: https://www.anticimex.se/byggsakring/, https://www.badrumshjalpen.se/
- [medium] Спрос на разрешение споров с мастерами стабилен. В ARN в категорию Bostad поступило 3 617 жалоб в 2023 году, 3 065 в 2024-м и 3 057 в 2025-м. Это аргумент в пользу услуги «oberoende kontroll mot offert/avtal» на Byggtorg, но не все эти жалобы касаются ремонта.
  Источники: https://www.arn.se/om-arn/statistik/

## Ограничения
Проверку прошли только данные по OpenSpace, Dalux, SDK, GDPR и шведским сервисам частного контроля. По Buildots, Doxel, Avvir, Cupix, HoloBuilder, StructionSite, Disperse, Reconstruct и Matterport подтверждённых утверждений нет: их точность, цены и сверку со сметой оценить нельзя. Нет проверенных данных о стоимости разработки MVP, о точности CV-детекции этапов работ и о том, применимы ли LLM или vision-модели для сопоставления со сметой. Не проверено, как это связано с AB04/ABT06, ÄTA и slutbesiktning. Цены вендоров и условия SDK могут меняться: репозиторий Insta360 на GitHub заморожен, доступ к SDK выдают по заявке. Юридические выводы о том, что kamerabevakningslagen не применяется к ручной 360-съёмке, — интерпретация, а не позиция IMY. Рекомендация «строить или интегрировать» отчасти опирается на синтез, а не на прямые источники.

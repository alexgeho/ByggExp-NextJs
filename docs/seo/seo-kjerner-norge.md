# SEO-ядра — Норвегия (byggexp.no)

Как получено: взят SE-список ключей → переведён на норвежский → прогнан через **Google Keyword Planner (гео Norway, язык Norwegian, 2026-09-07)** → сгруппирован в SEO-ядра. Ниже — ядра по убыванию объёма, с реальными объёмами и статусом (✅ построено).

Важно про перевод: шведские `tidrapport / tidrapportering / tidsregistrering` = по-норвежски **timeregistrering** (обиходно **timeliste**); `stämpelklocka` = **stemplingsur**; `personalliggare` = **mannskapsliste / oversiktsliste**. Поэтому 41 шведский ключ схлопывается в меньшее число норвежских ядер.

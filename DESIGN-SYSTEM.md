# ByggExp — дизайн-система (живой документ)

Один источник правил для всего сайта: калькуляторы, шаблоны, лендинги, блог.
Код правил: `src/styles/design-system.scss` (подключён последним в `_app.tsx`, побеждает старые стили).
Соцсети (посты, видео, обложки): `design-assets/social/DESIGN-SYSTEM-SMM.md`.
Общие принципы UI: `~/ui-principles.md` (минимум текста, близость, выравнивание, один акцент).

**Как работаем:** каждая правка владельца = новое правило ниже (номер, дата, что/почему, где в коде) + реализация в `design-system.scss` через токены. Перед показом любого UI — проверить ВСЕ правила этого файла (измерить `getBoundingClientRect`, скрин).

## Токены
| Токен | Значение | Где |
|---|---|---|
| `--ds-space-1..4` | 8 / 16 / 24 / 32 px | шаг сетки 8pt |
| `--ds-panel-pad` | 20px (≤900px: 16px) | внутренний отступ любой панели |
| `--ds-panel-radius` | 14px | скругление панелей |
| `--ds-panel-gap` | 22px | расстояние между соседними панелями |
Цвета/шрифты: `src/styles/globals.scss` (`--blue #2394ff`, `--ink`, `--muted`, `--line`, `--fs-h1..h3`).

## Правила
**R1 · 2026-10-19 · Соседние панели — одной высоты.**
Две панели в ряд (ввод | результат калькулятора) всегда равны по высоте; ни одна не «ниже» другой.
Код: `.lm-tool-split { align-items: stretch }`, `.lm-tool-aside .lm-result { flex: 1 }`.
Для `.lm-tool--split` (27 калькуляторов, левая колонка = стопка блоков): вся левая колонка — одна панель-подложка `::before`, растянутая на те же строки сетки, что и результат; внутренние рамки у сетки полей убраны; блоки колонки с отступом `--ds-panel-pad`. Только ≥901px, на телефоне колонки стопкой.
Проверено 2026-10-19: gips 549/549, betong 675/675, tak 822/822 px.

**R2 · 2026-10-19 · Ничего не прижато к краю панели. Эталон — левая панель калькулятора (20px).**
У всего содержимого панели одинаковый внутренний отступ `--ds-panel-pad` слева, справа и снизу. Кнопки внизу панели результата — с отступом панели, не впритык к рамке; в панелях равной высоты кнопки стоят у нижнего края.
Код: `.lm-result > .lm-tool-actions { padding: 0 var(--ds-panel-pad) var(--ds-panel-pad) }`, ряды и подпись результата — те же боковые отступы.

**R3 · 2026-10-20 · Ряд кнопок — одна линия.** Поле с подписью внутри ряда действий (Momssats, Enhet и т.п.) не уезжает ниже кнопок: подпись слева от поля, всё по центру одной линии, высота поля = высоте кнопки (46px).
Код: `.lm-tool-actions > .lm-tool-field { flex-direction: row; align-items: center }` + общая высота 46px. Почему: владелец — «выбор момса в ряд, а не смещался ниже» (faktura-mall).

**R4 · 2026-10-20 · Соседние секции — разный фон.** Две секции подряд никогда не одного цвета. Первый экран главной — фото на фоне, текст поверх (не «текст, потом картинка»). Дальше чередование: светлый `--bg` → белый `--white` → светлый → navy. Карточки на белой секции — с рамкой `--line`.
Код: `HeroV2 variant="dark"` на главной; `.pricing { background: var(--white) }` в design-system.scss. Почему: владелец — «сейчас всё одним фоном, текст и потом картинка — не то».

## Чек-лист перед показом
1. Соседние панели/кнопки одной высоты и радиуса (R1).
2. Ряд кнопок и полей — на одной линии, одной высоты (R3).
2c. Соседние секции разного фона, первый экран — фото с текстом поверх (R4).
2b. Внутренние отступы панели = `--ds-panel-pad` со всех сторон, ничего не касается рамки (R2).
3. Мобильный 390px: нет горизонтального скролла, панели в одну колонку.
4. Скриншот изменённого места до коммита.

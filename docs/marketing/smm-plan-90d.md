# ByggExp — SMM-план на 90 дней

Дата: 2026-10-19. Основа: Svenskarna och internet 2025, Nordicom 2025, бенчмарки Metadata/WordStream/Buffer.

## 1. Куда и зачем

| Соцсеть | Роль | Почему |
|---|---|---|
| **Facebook** (страница + группы) | Главная | 25+ в Швеции: охват 78–85 %, №1 по ежедневному использованию. Группы хантверкаров = готовая аудитория |
| **Instagram** | Дубль Reels | 64–75 % охвата, те же вертикальные видео без доп. работы |
| **YouTube @ByggExp** | Фабрика контента | 74–83 %, растёт (52 % смотрят ежедневно). Длинное видео → нарезка в Reels/Shorts |
| **LinkedIn** (страница компании + профиль Alex) | Вторичный | Владельцы фирм/прорабы. Ежедневно всего ~6 %, у рабочих ~18 % — 1 пост/нед |
| TikTok | Не сейчас | 7–14 % в возрасте 40–65 |

Языки: всё на шведском. Норвегия — отдельно, после запуска byggexp.no.

## 2. Воронка

Пост/видео → бесплатный инструмент на /sv/verktyg (калькулятор/шаблон → PDF, ловит e-post) → «14 dagar gratis» / «Boka demo» → клиент.
Правило: **в каждом посте 1 ссылка на 1 инструмент**, не на главную. UTM: `?utm_source=facebook&utm_medium=social&utm_campaign=smm-v{неделя}`.

## 3. Рубрики (ротация недели)

1. **Verktyg-tips** (пн) — 30-сек видео: «Räkna ut gips till ett rum på 20 sek» → ссылка на калькулятор.
2. **Pappersjobbet** (ср) — совет по ÄTA, egenkontroll, offert, faktura, personalliggare, kontrollavgift → шаблон.
3. **Så funkar det i ByggExp** (пт) — 1 функция, 1 боль: GPS-incheckning, ÄTA → faktura, Bemanning. Только проверенные факты (docs/seo/product-facts-verified.md).
4. **LinkedIn** (вт) — текст от Alex: цифра/правило/ошибка + шаблон в комментарии.

Не постить: выдуманные кейсы, отзывы, число клиентов, «интеграция с Fortnox» (только SIE4/CSV-экспорт), offline, авто-расчёт по Byggavtalet.

## 4. План по неделям

**Недели 1–2 — Запуск**
- Создать: FB-страницу ByggExp, Instagram Business (связать с FB), LinkedIn-страницу компании. Одинаковые аватар/обложка/ссылка `byggexp.se/sv/verktyg`.
- Meta Business Suite — планировщик для FB+IG (бесплатно).
- Вступить в 10–15 шведских FB-групп (hantverkare, snickare, byggföretagare, elektriker, VVS, egenföretagare bygg). Прочитать правила групп.
- Опубликовать 6 первых постов (раздел 5). В группах — только ответы на вопросы со ссылкой на инструмент, без рекламы в лоб.

**Недели 3–6 — Ритм**
- 3 поста/нед FB+IG + 1 LinkedIn. 1 длинное видео на YouTube в 2 недели → 3 нарезки.
- В группах: 3–5 полезных ответов в неделю.
- KPI недели: клики на /verktyg из соцсетей, e-post-лиды из ToolLeadForm.

**Недели 7–10 — Тест рекламы (Meta)**
- Бюджет 1 500–3 000 kr за 3 недели. Цель «Трафик/Лиды», Швеция, 30–60 лет, интересы: bygg, hantverkare, snickeri, egenföretagare.
- Продвигать 2 лучших органических поста (по CTR). Креатив = видео калькулятора.
- Ретаргетинг посетителей /verktyg → «14 dagar gratis».
- LinkedIn Ads не трогать: по бенчмаркам в 3–4 раза дороже за показ.

**Недели 11–13 — Масштаб того, что сработало**
- Оставить 1 лучшую рубрику ×2, слабую убрать.
- Повторить топ-3 поста в новом виде.
- Итог: отчёт трафик → лиды → демо/регистрации, решение по бюджету.

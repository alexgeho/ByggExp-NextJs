## Rangering av klynger (volum × B2B-intensjon × bud)

1. **KS / HMS / internkontroll / avvik** — flest hoder 100–1K (hms system, ks system, internkontrollsystem, kvalitetssystem, avvikssystem), ren B2B, høye bud (ks system opptil $59.6, enkelt hms system $21.7–64.2). Bygg-varianter finnes (10–100).
2. **Timeregistrering** — 4 hoder 100–1K, sterk app/kjøpsintensjon, jevne bud $5–12 (ansatte opptil $32). Bygg-konkurrenter (Smartdok, Svenn, SpeedyCraft, Handyman) søkes ved navn.
3. **Prosjektstyring / prosjektregnskap** — 3 hoder 100–1K, bygg-varianter med høyest bud i klyngen ($7.5–18.7). Hodet «prosjektstyring» er delvis kurs-/utdanningsintensjon.
4. **Faktura / tilbud** — høyt volum og bud, men intensjonen er generell småbedrift/ENK/«gratis», ikke håndverker (håndverker-varianter 0–10). tilbudsprogram 10–100 med høyt bud ($11.8–41.7).
5. **Planlegging** — bemanningsplan og fremdriftsplan 100–1K, men mest mal/excel-intensjon og lave bud.
6. **Generisk** — 10–100, svak/tvetydig intensjon.
7. **Dagbok** — 0–10 på alle varianter.

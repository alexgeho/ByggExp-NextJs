# Keywords — Norge (byggexp.no)

**Как пользоваться:** вставь термины ниже в **Google Keyword Planner** → *Discover new keywords* →
**Location: Norway**, **Language: Norwegian**. Заполни колонку «vol» реальными объёмами.
Затем страницы строим только под термины с объёмом (NO-рынок маленький — не переусердствовать).

⚠️ **НЕ бери шведские ключи** (tidrapport / stämpelklocka / personalliggare) — это `keywords-master.md`
для byggexp.se. Норвежцы ищут ДРУГИМИ словами. Ниже — норвежские эквиваленты твоего SE-списка + NO-специфика.

Ранняя прикидка (research Aug 2026, не Planner): top-термины ~500/mo (`timeregistrering app`,
`timeregistrering app gratis`, `stemplingsur`); остальное ~50 или нет данных. Уточнить в Planner.

Статус: ✅ покрыто nb-страницей · 🟡 частично · ☐ пробел (кандидат под новую статью)

## Пробелы-кандидаты (по приоритету, после проверки объёмов)
1. **timeliste mal (gratis PDF)** — лид-магнит-шаблон; норвежцы активно ищут (Jobbleder ранжируется). Behavioural SEO.
2. **timeregistreringssystem (bygg)** — если объём как в SE, отдельная «system»-статья.
3. **prosjektstyring bygg / prosjektstyringsverktøy** — broad, тянет весь продукт.
4. **faktura app bygg** — если объём есть, отдельно от faktureringsprogram.

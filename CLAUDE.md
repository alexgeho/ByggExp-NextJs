# ByggExp-NextJs

## Замечания владельца → правила (обязательно)
Любое замечание владельца по визуалу — сначала правило, потом правка:
- сайт / UI → новое правило R-N в `DESIGN-SYSTEM.md` + код в `src/styles/design-system.scss`;
- соцсети (посты, видео, обложки) → новое правило S-N в `design-assets/social/DESIGN-SYSTEM-SMM.md` + генератор.
Правка применяется ко всем таким же местам, не только к указанному. В ответе владельцу одной строкой: «Записал правило S-N/R-N: …».
Перед показом любого визуала — агент-критик без контекста (S9), показывать только после «чисто».
